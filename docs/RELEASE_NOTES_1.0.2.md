# Мяу, пора! 1.0.2 · тестовая сборка

- Вернулась **прежняя иконка приложения**. Новый милый котик остаётся внутри приложения.
- При запуске — только минималистичная вращающаяся таблетка, без текста и котика.
- Свайп вниз на «Сегодня» обновляет локальные приёмы, перепроверяет будильники и показывает новую фразу. Есть действие обновления для TalkBack.
- Быстрое добавление напоминания: выберите препарат из сохранённого списка с поиском, задайте дату/время и подтвердите. Не нужно заново вводить описание, дозировку или заметки. Из библиотеки быстрый редактор открывается отдельной кнопкой у препарата.
- Быстрый редактор поддерживает разовый и ежедневный приём. Для остальных вариантов есть переход к полной настройке. Совпадающий приём на выбранное время не дублируется. Если препарат был выключен, запускается только новое напоминание, а другие шаблоны остаются сохранёнными и выключенными.
- Действия для совместимых часов: «Принято», «На 10 минут», «Пропустить». Исправлены гонка восстановления будильника и обработка запоздавших действий уведомления.

## Обновление без повторного ввода данных

У APK повышены оба номера: **versionName 1.0.2, versionCode 3**. Имя пакета и схема Room не менялись. APK подписан тем же локальным ключом, что версии из Releases 1.0.0/1.0.1. Его можно установить поверх них: препараты, расписания, история, заметки, свои фразы и настройки сохраняются. Перед обновлением рекомендуется резервный экспорт, но удалять приложение не нужно.

Будущие push/ручные сборки Actions используют тот же ключ из зашифрованного GitHub Secret; ключ не хранится в исходниках. Старые CI-сборки и APK из pull request могут иметь другой сертификат. Если Android сообщает о несовпадении подписи, сначала экспортируйте данные из установленного приложения — системное ограничение подписи нельзя обойти.

## Samsung и часы

**На физических Galaxy / Galaxy Watch не проверено: устройства не подключены.** На Android проверяются системный будильник, уведомление и исполняемые действия. Пересылка через Galaxy Wearable, Bluetooth/LTE и особенности One UI требуют отдельной проверки на реальной паре устройств. В настройках приложения и [SAMSUNG.md](SAMSUNG.md) есть инструкция. Автономного приложения на часах нет; для старых часов Tizen поддержка кнопок отличается.

APK — debug-сборка, не медицинское изделие и не гарантия абсолютной точности Android-уведомлений.

## Проверки

Сборка, lint, **34 unit-теста и 17 Android-тестов** на API 29 прошли. Отдельно проверено обновление 1.0.0 → 1.0.2 без удаления: добавленный препарат, заметка, все строки Room и настройки сохранились. Статус дополнительной проверки CI на API 35 смотрите в Actions; это не тест физической прошивки Samsung.
