# Мяу, пора! 1.0.3 · тестовая сборка

- Возвращён **оригинальный минималистичный котик** внутри приложения (в соответствии со стилем версии 1.0.0 и иконкой приложения).
- Прежняя иконка на рабочем столе и в системе сохранена без изменений.
- При запуске — только минималистичная вращающаяся таблетка, без текста и котика.
- Свайп вниз на «Сегодня» обновляет локальные приёмы, перепроверяет будильники и показывает новую фразу. Есть действие обновления для TalkBack.
- Быстрое добавление напоминания из сохранённого списка с поиском, разовый и ежедневный приём.
- Действия для совместимых часов: «Принято», «На 10 минут», «Пропустить».

## Обновление без повторного ввода данных

У APK повышены оба номера: **versionName 1.0.3, versionCode 4**. Имя пакета `ru.meow.reminder` и схема Room не менялись. APK подписан тем же постоянным ключом, что и версии из Releases 1.0.0/1.0.1/1.0.2 (SHA-256 сертификата `e34c11293f9b67a0e1b1203ea52658725682ea92420fad7838f1ffc783667f4b`). Его можно установить поверх предыдущих версий: препараты, расписания, история, заметки, свои фразы и настройки сохраняются без потерь.

Обновление проверено на тестовом эмуляторе с версий 1.0.0 → 1.0.3 и 1.0.2 → 1.0.3 через `scripts/test-upgrade.py`.

## Samsung и часы

**На физических Galaxy / Galaxy Watch не проверено: устройства не подключены.** На Android проверяются системный будильник, уведомление и исполняемые действия. Пересылка через Galaxy Wearable, Bluetooth/LTE и особенности One UI требуют отдельной проверки на реальной паре устройств. В настройках приложения и [SAMSUNG.md](SAMSUNG.md) есть инструкция. Автономного приложения на часах нет.

APK — debug-сборка, не медицинское изделие и не гарантия абсолютной точности Android-уведомлений.

## Проверки

Сборка, lint, **34 unit-теста и 17 Android-тестов** на API 29 пройдены успешно. Отдельно проверено обновление без удаления: пользовательские препараты, заметки, настройки темы и все таблицы Room сохранились.
