# Мяу, пора! 1.0.0 · тестовая сборка

Нативное офлайн-приложение для Android 8.0 и новее: библиотека препаратов, гибкие расписания, AlarmManager, системные уведомления с действиями, история, добрые фразы и заметки с чек-листами. Material You (Android 12+), светлая и тёмная темы, котик с таблеткой, экспорт/импорт JSON. Разработчик L.

## Установка

1. Скачайте `meow-reminder-1.0.0-debug.apk` из Assets, откройте файл на телефоне.
2. Разрешите установку из выбранного источника, установите и откройте приложение.
3. Разрешите уведомления. В разделе «Настройки» проверьте точные будильники и тестовое уведомление.
4. Сохранённые примеры находятся в «Препараты → Сохранённые»; их напоминания выключены.

Локально пройдены 29 unit-тестов и 7 инструментальных тестов на Android 10, сборка и lint. APK установлен и проверен на эмуляторе; скриншоты в README настоящие.

**Важно:** это debug-подпись, не production/release-ключ. В будущих CI-сборках debug-ключ может отличаться: перед переустановкой обязательно экспортируйте данные. Для длительного распространения нужен постоянный release-ключ.

Anthropic Serif Web не включён без лицензии; используется Noto Serif (SIL OFL). OEM-ограничения батареи, длительный Doze и работу на физическом телефоне ещё нужно проверять отдельно. Приложение не назначает лечение и не гарантирует абсолютную точность Android-будильников. JSON не зашифрован. Заметки локальные, без облака и вложений.
