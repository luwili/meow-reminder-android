# Проверка на реальном телефоне

Автоматические тесты проверяют расчёт дат и состояния. Следующие проверки нужны отдельно для каждой прошивки; здесь они не помечены пройденными заранее.

- [ ] Первый запуск, отказ/разрешение POST_NOTIFICATIONS.
- [ ] Включение/отзыв доступа к точным будильникам, появление предупреждения и неточный резервный режим.
- [ ] Два разных препарата в одно время, несколько расписаний одного препарата.
- [ ] Уведомление при закрытом окне, заблокированном экране, после удаления приложения из списка недавних.
- [ ] Подтверждение и пропуск непосредственно из уведомления останавливают дополнительные повторы.
- [ ] Отсрочка 5/10/15/30 минут и свой интервал относится к одному приёму, не двигает завтра.
- [ ] Восстановление после перезагрузки, смены времени и часового пояса.
- [ ] Несколько пропущенных суток с выключенным телефоном: история неподтверждена, пачка старых уведомлений не приходит.
- [ ] Отключение/архивирование/удаление отменяет будущие будильники, история остаётся.
- [ ] Работа в Doze и при OEM-ограничениях батареи; проверить фактические задержки, не обещать точность.
- [ ] Force-stop: ожидается отсутствие доставки до следующего ручного открытия (ограничение Android).
- [ ] Последний приём конечного курса: после него основное расписание не создаёт новые приёмы.
- [ ] Ночной переход через полночь, последний день месяца, 29 февраля, DST gap/overlap.
- [ ] Светлая/тёмная темы, Material You с разными обоями, крупный системный шрифт, TalkBack, поворот экрана.
- [ ] JSON экспорт → сброс → импорт и повторное объединение: без дублей по ID.
- [ ] Большая заметка, длинный чек-лист, поиск, закрепление и архив после перезапуска.

Во время проверки не используйте тестовые напоминания как единственный способ контроля важных назначений.
