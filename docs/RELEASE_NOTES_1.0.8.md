# Мяу, пора! 1.0.8

- Добавлена вкладка календаря: неделя начинается с понедельника, текущая дата и часовой пояс берутся с устройства.
- Цветные точки показывают препараты, запланированные на день; под календарём находится список активных препаратов.
- При выборе дня можно посмотреть приёмы, открыть редактирование расписания и добавить напоминание с выбранной даты.
- Приложение не подключается к системному календарю и не синхронизирует его события.

Обновляйте поверх предыдущей версии, не удаляя приложение. Перед обновлением рекомендуется экспортировать данные. Проверка на физическом Samsung не выполнялась.
