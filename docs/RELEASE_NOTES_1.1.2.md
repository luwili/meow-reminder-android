# Мяу, пора! 1.1.2

- Количество таблеток или объём сиропа задаётся в расписании и может быть изменён для отдельного приёма. Дозировка препарата указывается отдельно.
- В календаре месяцы листаются свайпом; приёмы выбранного дня показаны отдельно, с количеством и дозировкой.
- Разовый приём можно добавить в выбранный день из сохранённого или нового препарата. Для таблетки при пустом поле используется 1; для сиропа объём вводится явно.
- Миграция Room 1 → 2 сохраняет записи: количество в старой истории остаётся неизвестным, если оно не было записано.
- Подпись APK и идентификатор приложения сохранены. Перед обновлением рекомендуется экспортировать резервную копию.

Проверки выполнены на эмуляторе Android; проверка на физических Samsung Galaxy / Galaxy Watch не выполнялась. Приложение не назначает лечение и не рассчитывает дозировку.
