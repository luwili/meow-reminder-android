# Правила проекта «Мяу, пора!»

- Сохранять `applicationId = ru.meow.reminder`. Обновления должны устанавливаться поверх предыдущих APK без повторного ввода препаратов, расписаний, истории, заметок, фраз и настроек.
- При каждом новом опубликованном выпуске повышать `versionName` и `versionCode` в `app/build.gradle.kts`. Номер версии в интерфейсе брать из BuildConfig. Не переиспользовать номер уже опубликованной версии для другого APK.
- Room: при изменении схемы добавлять явную миграцию и тест сохранности данных. Не применять destructive migration и не сбрасывать DataStore при обновлении. Примеры не должны создаваться повторно.
- Сохранять подпись совместимых обновлений. CI получает ключ из `MEOW_UPDATE_KEYSTORE_BASE64`; ключи и пароли не должны попадать в исходники, артефакты или логи. Не генерировать другой ключ для распространяемых обновлений. См. `docs/UPDATING.md`.
- Оставлять прежнюю иконку launcher и оригинального минималистичного котика из версии 1.0.0, если пользователь отдельно не попросил их изменить. На загрузке только вращающаяся таблетка.
- Проверять `testDebugUnitTest`, `lintDebug`, `assembleDebug` и доступные `connectedDebugAndroidTest`. При изменениях обновления использовать отдельный эмулятор и `scripts/test-upgrade.py`, не личный телефон.
- Не называть тесты эмулятора проверкой Samsung Galaxy / Galaxy Watch. Для такой проверки нужны физические устройства; статус и ограничения описывать честно.
- По запросу пользователя на публикацию обновлять исходники, документацию и APK в существующем отдельном репозитории `luwili/meow-reminder-android`, не затрагивая другие программы. Не перезаписывать старые опубликованные APK.
